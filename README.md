# IT Passport (IP) Exam — প্রশ্নব্যাংক, উত্তর ও বাংলা ব্যাখ্যা

ITPEC **IT Passport Examination (IP)** এর ৩৩টি পুরনো প্রশ্নপত্র (April 2010 – April 2026) থেকে তৈরি একটি স্ট্যাটিক স্টাডি সাইট। HTML + CSS + vanilla JS, কোনো বিল্ড টুল লাগে না — সোজা GitHub Pages এ দেওয়া যায়।

## কী আছে

- **৩,২৯৩টি প্রশ্ন** উত্তরসহ, **১,৬৯৪টি প্রশ্নগুচ্ছে** (একই প্রশ্ন বিভিন্ন বছরে যেভাবে এসেছে, এক গুচ্ছে)
- **গুরুত্বের ক্রমে সাজানো**: যে প্রশ্ন সবচেয়ে বেশিবার এসেছে (সর্বোচ্চ ১৫ বার) সেটি সবার উপরে
- **২২০টি বিস্তারিত বাংলা ব্যাখ্যা** (সবচেয়ে বেশি রিপিট হওয়া গুচ্ছগুলোতে): কেন এই উত্তর → যা মনে রাখতে হবে → আরও যে টপিক পড়বেন
- **সম্পর্কিত পুরনো প্রশ্ন** প্রতিটি কার্ডে হাইড করা অবস্থায় (চাইলে একসাথে পড়া যায়) — পেজের শুরুতেই বেছে নেওয়া যায় "শুধু গুরুত্বপূর্ণ" না "সম্পর্কিত প্রশ্নসহ"
- **১৪টি কুইক নোট**: পরীক্ষার প্যাটার্ন, ৪ দিনের রোডম্যাপ, সময় বাঁচানোর কৌশল, প্রতি টপিকের সারসংক্ষেপ, "প্রায় নিশ্চিত ২০টি বিষয়"
- **কুইজ মোড** (২০ প্রশ্ন, সাথে সাথে ব্যাখ্যা ও স্কোর), টপিক/ক্ষেত্র/বছর ফিল্টার, সার্চ, "শেখা হয়েছে" প্রগ্রেস (localStorage)
- **প্রতিটি প্রশ্নের মূল ছবি** (`img/`): PDF থেকে প্রতিটি প্রশ্ন আলাদা করে কেটে আনা — চিত্র, টেবিল, ফ্লোচার্ট সব হুবহু। চিত্রভিত্তিক প্রশ্নে ছবি আগে দেখানো হয়, বাকিগুলোতে এক ক্লিকে
- প্রতিটি কার্ড থেকে **পুরো PDF** খোলা যায় (`pdf/` ফোল্ডারে সব প্রশ্নপত্র ও উত্তরপত্র)
- SEO: বাংলা ও ইংরেজি মেটা ট্যাগ, Open Graph, `WebSite`/`Course`/`FAQPage` JSON-LD, ক্রল করার মতো স্ট্যাটিক ৩০টি প্রশ্নোত্তরের ব্লক, `sitemap.xml`, `robots.txt`

## GitHub Pages এ ডিপ্লয়

```bash
# ১) এই site/ ফোল্ডারের ভেতর থেকে
cd site

# ২) নিজের GitHub ইউজারনেম ও রিপো নাম বসিয়ে URL ঠিক করুন
#    (উদাহরণ: ইউজারনেম subroto-das, রিপো ip-exam)
sh set-url.sh subroto-das ip-exam

# ৩) গিট রিপো বানিয়ে পুশ করুন
git init
git add -A
git commit -m "IP exam question bank with Bangla explanations"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

এরপর GitHub এ রিপোর **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / root** দিন। ১–২ মিনিট পর সাইট পাওয়া যাবে:
`https://<username>.github.io/<repo>/`

> রিপোর রুটে `site/` ফোল্ডারটাই রাখলে সবচেয়ে সহজ। চাইলে ফোল্ডারের সব ফাইল রিপোর রুটে রাখুন, অথবা Pages এর Source এ `/site` ফোল্ডার বেছে দিন।
> `.nojekyll` ফাইলটি মুছবেন না — এটি না থাকলে GitHub Pages কিছু ফাইল স্কিপ করতে পারে।

## সার্চে খুঁজে পাওয়ার জন্য (প্রথম ডিপ্লয়ের পর)

1. [Google Search Console](https://search.google.com/search-console) এ সাইটটি যোগ করুন (URL prefix), মালিকানা যাচাই করুন
2. `https://<username>.github.io/<repo>/sitemap.xml` সাবমিট করুন
3. হোম URL টি "URL Inspection → Request indexing" দিয়ে একবার পাঠান
4. রিপোর About/description এ সাইট লিংক দিন, আর যেকোনো গ্রুপ/পোস্টে লিংক শেয়ার করুন — ব্যাকলিংক ইনডেক্স দ্রুত করে

## লোকালি দেখা

```bash
cd site && python3 -m http.server 8080
# ব্রাউজারে: http://localhost:8080
```

(সরাসরি `index.html` ডাবল-ক্লিক করলে `fetch` ব্লক হতে পারে, তাই লোকাল সার্ভার ব্যবহার করুন।)

## ফাইল স্ট্রাকচার

```
site/
├── index.html          # পেজ (SEO ব্লক ইনজেক্ট করা)
├── index.tpl.html      # টেমপ্লেট (ডেটা রিবিল্ড করলে এর থেকে index.html বানানো হয়)
├── assets/app.css      # স্টাইল (লাইট/ডার্ক)
├── assets/app.js       # পুরো অ্যাপ লজিক (নির্ভরতা ছাড়া)
├── data/bank.json      # প্রশ্ন + উত্তর + ব্যাখ্যা + নোট (~৩ MB)
├── img/<exam>/q###.png # প্রতিটি প্রশ্নের মূল ছবি (চিত্র/টেবিলসহ)
├── pdf/<exam>/*.pdf    # মূল প্রশ্নপত্র ও উত্তরপত্র
├── sitemap.xml, robots.txt, .nojekyll
└── set-url.sh          # canonical/OG/sitemap URL বদলানোর স্ক্রিপ্ট
```

## উৎস ও নোট

- প্রশ্ন ও সঠিক উত্তর ITPEC প্রকাশিত প্রশ্নপত্র/উত্তরপত্র থেকে স্বয়ংক্রিয়ভাবে বের করা। যেসব প্রশ্নের অপশন ছবিতে ছিল সেগুলোও ছবি হিসেবে যোগ করা আছে (উত্তরসহ)।
- চিত্রনির্ভর প্রশ্নে টেক্সটে ছবি আসে না, তাই কার্ডের নিচের PDF লিংক ব্যবহার করুন।
- ব্যাখ্যাগুলো বাংলায় লেখা, কিন্তু পরিভাষা ইংরেজিতেই রাখা হয়েছে — কারণ পরীক্ষায় প্রশ্ন ইংরেজিতেই আসবে।
